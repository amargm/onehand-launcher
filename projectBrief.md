# Project Brief: One-Handed OS (Obsidian Pulse)

## 1. Vision & Purpose
A mobile operating system interface designed for extreme ergonomics and high-efficiency one-handed use. The "Obsidian Pulse" aesthetic utilizes a deep dark-mode palette with high-contrast accents (ranging from vibrant orange to monochromatic white) to provide a premium, focused user experience.

## 2. Design Principles
- **Ergonomic Reachability:** All primary interactive elements are grouped in the bottom third of the screen, the "thumb zone," to minimize hand strain and maximize reachability.
- **Concentric Hierarchy:** Information flows from the bottom up, with secondary context-aware notifications appearing above primary controls.
- **Visual Precision:** Perfectly circular iconography and compact typography (Sora) create a refined, technical, and high-precision feel.
- **Deep Immersion:** A dark-mode first interface using pure black backgrounds and refined charcoal containers to reduce eye strain and emphasize interactive elements.

## 3. Core Interface Components
- **The Compact Concentric Dock:** A narrowed, centered container housing four primary circular buttons with equal spacing. Includes three quick-access folders and a dedicated search function on the right.
- **Dynamic App Grid:** A centered 4x2 grid of perfectly circular app icons positioned directly above the dock for maximum reachability within the thumb zone.
- **Minimalist Lock Screen:** Left-aligned clock and date with a refined, small-scale typographic treatment to prioritize negative space and clarity.
- **Context-Aware Section:** A flexible area at the top of the screen (e.g., "Context Active" pill) that surfaces high-level system status or active tasks.

## 4. Technical Specifications
- **Device Type:** Mobile (Portrait orientation).
- **Primary Font:** Sora (Refined weights, high-tracking).
- **Color Palette:**
  - **Primary Background:** #000000 (Pure Black)
  - **Section Containers:** Dark Grey/Charcoal (#1a1a1a to #262626)
  - **Accent Variations:** #ff5722 (Orange), White (#ffffff), or Slate Blue.
- **Shape Language:** Full roundness (Circular) for all interactive icons and high-radius rounding for containers.

## 5. Visual Variations
- **Amber/Orange Pulse:** The signature high-energy aesthetic using vibrant orange for active states and search.
- **Monochromatic Stealth:** A high-contrast black-and-white version for a technical, minimal look.
- **Midnight/Slate:** Cooler tonal variations using deep blues and charcoals for a nocturnal mood.

## 6. User Journey
1. **At a Glance:** User views left-aligned time/date on a clean, pure black backdrop.
2. **Quick Launch:** User taps circular app icons in the lower-third grid, all within easy thumb reach.
3. **Category Navigation:** User utilizes the compact dock to switch between app folders or initiate a global search.
4. **System Feedback:** Contextual pills at the top provide non-intrusive status updates.
