# One-Handed Launcher

A Flutter Android home-screen launcher focused on ergonomic one-handed use.

## Development

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

The Android package ID is `com.onehand.onehand_launcher`. Keep it unchanged
after creating the Play Console app.

## Google Play releases

See the [Play Store release guide](docs/PLAY_RELEASE.md) for the release
readiness checklist, upload-key and service-account setup, and the tagged
GitHub Actions workflow for internal testing releases. The
[privacy policy](docs/privacy/index.html) is published to GitHub Pages at
https://amargm.github.io/onehand-launcher/.
